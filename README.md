# سبورة الرياضيات العربية الذكية (PWA)

سبورة حرّة للكتابة بالقلم على تابلت أندرويد لتدريس الرياضيات (المنهج المهني العراقي).
**الحالة: المرحلة 1 فقط** (السبورة، الأدوات، الحفظ، الطباعة بحجم 16px، PWA). التعرّف الآلي، تنظيم الصفحات وPDF **غير منفّذة بعد**.

## التشغيل
```bash
npm install          # لاختبارات الواجهة فقط (playwright-core)؛ التطبيق نفسه بلا اعتماديات
npm start            # خادم ملفات ثابتة على المنفذ 8080
npm test             # اختبارات الوحدة (Node)
npm run test:e2e     # اختبارات الواجهة على Chromium (يتطلب Chromium؛ CHROMIUM_PATH اختياري)
```

## المعاينة على تابلت أندرويد
1. **عبر USB (موصى به — يفعّل التثبيت والعمل دون اتصال):** فعّل خيارات المطوّر وتصحيح USB، ثم على الحاسوب:
   `npm start` و `adb reverse tcp:8080 tcp:8080`، وافتح في Chrome على التابلت `http://localhost:8080`.
   `localhost` سياق آمن فيعمل Service Worker وخيار «تثبيت التطبيق».
2. **عبر الشبكة المحلية:** شغّل `npm start` وافتح عنوان IP المطبوع (مثل `http://192.168.1.20:8080`) على التابلت نفسه الشبكة.
   الرسم والحفظ المحلي يعملان، لكن المتصفح **لا يسمح** بـ Service Worker/التثبيت على HTTP غير الآمن.
3. **للاستخدام الفعلي:** انشر المجلد كما هو على أي استضافة HTTPS ثابتة (لا توجد خطوة بناء)، ثم «إضافة إلى الشاشة الرئيسية».

> لم تُختبر النسخة على جهاز أندرويد حقيقي بعد؛ الاختبارات أُجريت على Chromium (محاكاة قلم ولمس عبر CDP).

## البنية
| الملف | الدور |
|---|---|
| `js/model.js` | نموذج الدرس، التراجع/الإعادة، الهندسة (نقي، مُختبر) |
| `js/store.js` | IndexedDB + الحفظ التلقائي (`Autosaver`) |
| `js/board.js` | الرسم، القلم/اللمس، التكبير/التحريك، كائنات النص |
| `js/app.js` | ربط الواجهة والحوارات والمحرر |
| `sw.js`, `manifest.webmanifest` | PWA |
| `fonts/` | Noto Naskh Arabic (ترخيص OFL) مضمَّن للعمل دون اتصال |

## قرارات تصميم
- الخطوط اليدوية تُخزَّن كنقاط (x,y,ضغط) منفصلة عن كائنات النص، فتبقى الكتابة الأصلية دائمًا عند ظهور نص مطبوع.
- حجم النص الافتراضي 16px لكل درس جديد؛ يُحفظ مع الدرس؛ تغييره لا يعدّل النصوص الموجودة (يُعدَّل حجم كل نص من محرره).
- إذا اكتُشف قلم فإن لمس إصبع واحد يحرّك السبورة ولا يرسم (رفض الكف)؛ بدون قلم يرسم الإصبع.
- الممحاة تحذف الخط كاملًا (قابل للتراجع)، لا تمحو أجزاءً منه.

## قيود معروفة
- لا تعرّف على الكتابة (عربية أو معادلات) — زر «تعرّف» موسوم «غير مفعّل» ولا ينتج شيئًا.
- لا تنظيم صفحات ولا PDF (المرحلة 3).
- لم تُنفَّذ بعد: تحديد وتحريك عدة عناصر معًا، تصدير/استيراد ملف درس، رسم أشكال.
